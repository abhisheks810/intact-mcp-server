# Generated Data

This directory is the default `INTACT_WORKSPACE`.

The MCP server writes generated planning artifacts here:

- `decisions/`
- `product-briefs/`
- `agent-specs/`
- `research-notes/`
- `map-platform-tasks/`
- `map-platform-patch-proposals/`
- `map-platform-change-requests/`
- `map-platform-implementation-results/`
- `agent-runs/`

These artifacts are markdown by design so they can be reviewed and committed when useful.
